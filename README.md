# Piano Music Theory & Chord Visualizer

This tool is designed to help pianists and producers explore scales, map out the keyboard across octaves, and dynamically generate chord voicings and inversions.

## Live Application
To make this tool as accessible as possible, it is hosted online via Streamlit Community Cloud. You can access and interact with the application directly from your browser without needing to download or run any code locally:

https://piano-music-theory-chord-visualizer-hvhtrdcfjb4xt6ok3mzymb.streamlit.app

## Core Features
- **Dynamic Keyboard Mapping:** Visualizes scales and intervals across the keyboard based on your chosen root note and scale type.
- **Chord Inversions:** Explore Root Position, 1st Inversion, and 2nd Inversion voicings directly on the keyboard.
- **Diatonic Chords & Progressions:** Maps out all 7 diatonic chords and common progressions, including Pop (I - V - vi - IV), Classic Rock (I - IV - V), and Jazz/R&B (ii - V - I).
- **Multilingual Support:** The interface is fully accessible in English, Chinese (中文), and French (Français).

## Running the Application Locally
If you wish to run this tool on your own machine, please follow these steps:
1. Ensure you have Python installed.
2. Install the necessary dependencies by running: `pip install -r requirements.txt`
3. Launch the application with the command: `streamlit run app.py`
